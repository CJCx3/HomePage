MTTD

A desktop music player where the machine is the interface. Instead of generic buttons, you control the Spotify you’re already playing through five fully-realized, era-authentic devices.

Windows Desktop app · Electron Needs Spotify Premium
Download for Windows · 79 MB

MTTD-Setup-1.0.0.exe · Windows 10/11 · installs in seconds · hosted on GitHub Releases.

Install it

  1. Download the installer above.
  2. Open MTTD-Setup-1.0.0.exe. It isn’t code-signed yet, so Windows SmartScreen may say “Windows protected your PC” — click More info → Run anyway.
  3. It installs and opens to the collection room, where you pick a machine.
  4. Connect Spotify: MTTD opens Spotify’s own login in your browser (PKCE — it never sees your password). A Spotify Premium account is required, because the Web API only allows playback control on Premium.
  5. Start Spotify playing on any device, pick one of the five machines, and drive it with its physical controls.

The five machines

  • Vinyl Player — browse a record crate; click the tonearm to play, drag the record to cue/scrub, 33/45 switch, VU meters.
  • Cassette Player — a pile of J-card tapes; molded REW/PLAY/F.FWD/STOP keys, spinning reels, tape counter, A/B rocker.
  • Walkman — a CD cabinet with pull-out drawers; the lid opens, the disc drops and spins, HOLD switch, volume roller.
  • Boombox — flip a side rack like a jukebox; VOLUME/BASS knobs, dual speakers that pulse, a live graphic EQ, neon.
  • iPod — the classic scrolling menu; the click wheel is everything — rotate to scroll/scrub, center to select.

Why it exists

Streaming flattened every album into the same grid of buttons. MTTD gives the music back a body: no floating HUD, no emoji — every control is a physical part of a machine you’d actually have owned, from the 1950s crate to the 2000s click wheel. It’s a remote for the Spotify you already pay for, dressed as the gear that made listening feel like an occasion.
