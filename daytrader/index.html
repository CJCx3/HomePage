DayTrader

A small, honest day-trading bot. Costs are always modelled, buy-and-hold is always the benchmark, and a max-daily-loss kill-switch is always on. It defaults to paper trading — simulated orders, zero financial risk.

Python 3.11+ Command line Alpaca · paper by default
Download source · .zip

daytrader-source.zip · code only (no keys) · cross-platform.

Set it up

  1. Install Python 3.11+ from python.org (on Windows, tick “Add Python to PATH”).
  2. Download and unzip the source above, then open a terminal in the daytrader folder.
  3. Create an environment and install dependencies: 
    python -m venv venv
# Windows:  venv\Scripts\Activate.ps1
# mac/linux: source venv/bin/activate
pip install -r requirements.txt
  4. No keys needed to explore. Backtest a strategy against buy-and-hold on free daily data: 
    python scripts/run_backtest.py --strategy ma_crossover --source yfinance --resolution 1Day --start 2018-01-01
  5. To paper-trade: make a free account at alpaca.markets, switch to the Paper view, generate keys, then copy .env.example .env and paste your paper ALPACA_API_KEY / ALPACA_SECRET_KEY.
  6. Check everything, then watch it trade (paper) during US market hours: 
    python scripts/preflight.py
python scripts/run_live.py

The safety rails

  • Paper by default. Real-money live mode refuses to start unless you set i_understand_live_risk: true in config.yaml.
  • Kill-switch is mandatory. If the session loss reaches risk.max_daily_loss, it flattens everything, halts, and stays tripped until you reset it.
  • Costs are always modelled (commission + slippage). Every comparison includes buy-and-hold; if nothing beats it out-of-sample after costs, it reports “NO EDGE FOUND” and promotes nothing.

Why it exists

Most trading bots sell a fantasy: a green backtest with the costs quietly deleted. DayTrader is the opposite — it’s built to tell you the truth, including the truth you don’t want. It models every cost, benchmarks against simply holding, and is happy to conclude that your clever strategy is worse than doing nothing. The point isn’t to get rich; it’s to see exactly how a real trading machine behaves, safely.

Not financial advice. Risk only money you can afford to lose. A backtest is not a prediction, and automating a losing strategy just loses money faster.
